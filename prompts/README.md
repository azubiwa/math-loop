# 問題生成プロンプト集

- `level-1-10-contests.md`: 導入〜学部前半向け。10回 × A〜Eの50問を一括生成
- `level-2-10-contests.md`: 学部前半〜中盤向け。10回 × A〜Eの50問を一括生成
- `level-3-10-contests.md`: 学部後半向け。10回 × A〜Eの50問を一括生成
- `review-generated-problems.md`: 生成済みJSONの数学的正しさ、採点条件、解説を検査・修正

各ファイルのコードブロック内をAIへ貼り付けて使います。生成後はレビュー用プロンプトにJSONを渡してからアプリへ追加してください。

現在のアプリはA〜Eの問題に対応しています。
