# 問題生成プロンプト集

- `level-1-10-contests.md`: 大学初年級の標準問題＋高校数学の解析的計算。10回 × A〜Eの50問を一括生成
- `level-2-10-contests.md`: 学部後半の基礎。10回 × A〜Eの50問を一括生成
- `level-3-10-contests.md`: 難関大学院入試相当の総合発展。10回 × A〜Eの50問を一括生成
- `guided-set.md`: 独立カテゴリー「テーマ演習」。既存セットの索引を基に、重複しない連番の新規セットを生成
- [grid25.md](grid25.md): 25マス計算。行5個×列5個から作る問題セット案、全25マスの正答・解説を生成
- `review-generated-problems.md`: 生成済みJSONの数学的正しさ、採点条件、解説を検査・修正

各ファイルのコードブロック内をAIへ貼り付けて使います。`guided-set.md`を使うときは、生成条件の`{EXISTING_GUIDED_SET_CATALOG}`へ既存テーマ演習の索引を渡してください。通常のLevel問題は生成後にレビュー用プロンプトへJSONを渡してからアプリへ追加してください。

通常のLevel問題は `lib/problem-data.json`、テーマ演習は親セットと5小問の関係を保ったまま `lib/guided-set-data.json` に追加します。

25マス計算の生成には `grid25.md` を使い、対象演算・難度の既存索引を渡します。出力は追加実装用の問題案です。現在はコードで問題を生成するため、そのJSONを通常問題データや履歴の読み込みへ渡すことはできません。生成後の検算・採用手順も同ファイルを参照してください。
