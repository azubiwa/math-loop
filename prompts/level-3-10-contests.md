# Level 3：10回分一括生成プロンプト

```text
あなたは、大学数学の問題作成・校正・解説執筆を担当する専門家です。
学習アプリ「MathLoop」向けに、学部後半レベルの「Level 3」を独立した10回分、一括作成してください。

ここでLevel 3とは、大学3〜4年生を主対象とし、定義や定理を知っているだけでなく、適用条件の確認、反例の構成、複数分野の接続、証明方針の発見を問う発展レベルを意味します。大学院の専門講義や未提示の高度な定理を前提にしてはいけません。

## 作成数

- 「Level 3 #001」から「Level 3 #010」までの10回分
- 各回A、B、C、D、Eを1問ずつ
- 合計50問。欠番、重複、追加問題は禁止
- 配列内の順序は #001-A, #001-B, ... #001-E, #002-A, ... #010-E とする

## 難易度

- A: 学部後半の基本定義・標準定理を正しく使う問題。目安15分、200点
- B: 仮定の確認を含む標準的な証明・計算。目安25分、300点
- C: 複数の命題を組み合わせる問題、または反例構成。目安40分、400点
- D: 非自明な補題や着眼を要する発展問題。目安60分、500点
- E: 複数分野の接続や独創的な方針を要する回の主問題。目安90分、700点

難しさを長い計算、煩雑な場合分け、特殊な知識の暗記だけで作らない。
Aでも学部後半らしい概念理解を問い、Eでも提示された周辺知識と標準的な学部知識から解説を追えるようにする。

## 分野構成

10回全体で次を偏りなく扱い、少なくとも各分野から複数問を出す。

- 実解析：距離空間、完備性、関数列、一様収束、測度、Lebesgue積分
- 複素解析：正則関数、Cauchyの積分定理、留数、解析接続の初歩
- 線形代数・関数解析の初歩：双対、内積空間、スペクトル、ノルム空間
- 抽象代数：群作用、Sylowの定理、環・イデアル、体拡大の初歩
- 位相空間論：コンパクト性、連結性、商空間、積位相、分離公理
- 微分幾何・多様体の初歩：接空間、正則値、微分形式の基本
- 確率論：確率変数、収束概念、条件付き期待値、極限定理の基本
- 常微分方程式：存在一意性、線形系、安定性の初歩

1つのE問題を無理に多数分野へまたがらせない。接続が自然で、数学的な学びがある組合せだけを使う。
外部資料が必要な専門用語や、学部範囲を超える定理を使う場合は、問題文内で必要な命題を明示する。

## JSON出力

出力は有効なJSON配列だけにする。Markdown、コードフェンス、前置き、後書き、コメント、省略記号は一切出力しない。
JSON文字列内のバックスラッシュは正しくエスケープする。すべてのキーと文字列をダブルクォートで囲む。

各問題を必ず次のスキーマで作る。

{
  "id": "L3-001-A",
  "contest": "Level 3 #001",
  "difficulty": "A",
  "score": 200,
  "title": "簡潔で内容が分かるタイトル",
  "field": "主分野を1つ",
  "tags": ["具体的な知識タグ", "具体的な知識タグ"],
  "minutes": 15,
  "answerType": "short または proof",
  "prompt": ["定義と仮定を含む自己完結した問題文", "必要な条件や数式"],
  "note": "必要な場合だけ記載する注記",
  "explanation": {
    "summary": "最終的な結論と証明方針の要約",
    "steps": [
      "使用する定義・定理と適用可能性の確認",
      "途中を飛ばさない主要な推論",
      "結論"
    ],
    "knowledge": [
      {
        "title": "必要な定義",
        "body": "量化記号や対象を曖昧にせず、簡潔かつ正確に説明する。"
      },
      {
        "title": "中心となる定理",
        "body": "定理の仮定と結論、この問題での適用方法をまとめる。"
      },
      {
        "title": "関連概念・注意点",
        "body": "類似概念との差、仮定を外した場合の反例、他分野との接続のいずれかをまとめる。"
      }
    ]
  },
  "grade": {
    "type": "keywords",
    "groups": [
      ["必須論点1の具体的表現", "同じ論点の別表記"],
      ["必須論点2の具体的表現", "同じ論点の別表記"],
      ["最終結論の具体的表現", "最終結論の別表記"]
    ],
    "hint": "方針を示すが答えを直接明かさない短いヒント"
  }
}

noteが不要ならnoteキーを省略する。
原則としてproof + keywordsを使う。ただし答えが短い文字列で一意に定まり、論証を採点する必要がない問題だけshort + exactを使ってよい。
exactの場合のgradeは次の形にし、groupsを出力しない。

{
  "type": "exact",
  "accepted": ["正答", "数学的に同値な別表記"],
  "hint": "回答形式の短い説明"
}

## 問題の品質基準

- 問題文だけで対象、仮定、記号、結論が一意に分かるようにする。
- 定理名だけを答えさせず、なぜ適用できるか、または何が結論できるかを問う。
- 定理の仮定を意図的に外す場合は、反例や失敗理由を明確に問う。
- 存在を主張する問題では、必要に応じて選択公理などの基礎的前提に依存しない範囲にする。
- 病的な反例や専門的な構成を前提知識なしで要求しない。
- 記号、添字、量化の順序、写像の定義域・値域を厳密にする。
- 数式はUnicodeまたは簡潔なTeX風表記で統一する。
- 50問の結論、題材、中心的解法が実質的に重複しないようにする。

## 解説と周辺知識

- summaryには結論だけでなく、証明の中心となる着眼を明記する。
- stepsは補題、定理の適用条件、主要な評価・構成、結論の順に書く。
- 重要な推論を「明らか」「同様」で飛ばさない。
- knowledgeは原則3〜5項目とする。
- 必要な定義を、量化の順序を含めて正確に説明する。
- 使用する定理は仮定と結論を示し、この問題で各仮定がどう満たされるかを書く。
- 周辺知識として、関連定理、仮定を弱めたときの反例、似た収束概念との差、他分野との自然な接続などを1〜2項目含める。
- 周辺知識は短い教科書ノートとして役立つ密度にしつつ、問題と無関係な一般論で水増ししない。
- 高度な結果を使う場合は、その結果自体をknowledgeで説明するだけで済ませず、問題文で使用可能な定理として提示する。

## 採点条件

keywordsのgroupsは、証明に必須な独立論点を1グループずつ表す。
同じgroupには同義表現だけを入れ、別々の論点を混ぜない。
「連続」「コンパクト」のような一般語1語だけを避け、誤検出しにくい具体的な式や主張にする。
模範解答stepsの主要論点とgroupsを一対一に近い形で対応させる。
結論だけ書いた答案が正解にならないよう、理由・適用条件・主要な中間結果もgroupsに含める。

exactは回答全体の完全一致である。acceptedには正しい別表記を列挙するが、誤答や根拠のない近似値を含めない。
許容誤差判定はできないため、数値近似だけを答えさせる問題は作らない。

## IDとメタデータ

- idはL3-001-AからL3-010-Eまでとする。
- contestはidの回号と一致させる。
- difficulty、score、minutesは上記の難易度表に合わせる。
- tagsは2〜5個とし、検索に役立つ具体語を使う。

## 出力前の内部検査

出力前に全50問を内部で検査する。検査結果は出力しない。

1. 各問題を実際に解き、命題、答え、証明、周辺知識に誤りがないか。
2. 定理の仮定をすべて確認し、暗黙の有限性・可測性・完備性などが抜けていないか。
3. 10回 × 5問が揃い、ID、contest、difficultyに欠番や重複がないか。
4. 各回でAからEへ難易度が上がっているか。
5. explanationの結論とgradeの判定条件が一致しているか。
6. knowledgeが正確で、問題に必要な定義・定理・周辺知識を含むか。
7. keywordsのgroupsが証明の必須論点を過不足なく表すか。
8. 50問全体で分野と解法に十分な多様性があるか。
9. JSONとして構文が完全に正しく、余計な文章がないか。

一度に50問すべてを省略せず出力してください。
```
